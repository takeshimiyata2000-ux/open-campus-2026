# ドッキングラボ（試作版）

`pocket_game/` を発展させた、手動ドッキングのゲームです。`pocket_game/` とは独立しています。

- 水素結合が成立すると、緑の点線と相手のアミノ酸名がその場で表示されます。
- スコアは水素結合、金属への配位、ポケットへの収まり、疎水性の接触、静電相互作用、衝突の合計で、結晶構造のポーズを 100 点として換算します。
- 「答え合わせ」で、結晶構造の結合ポーズとのずれ（RMSD）を表示します。2 Å 以内を成功とします。
- 上級では、低分子の結合をスライダーでねじれます。
- 「ヒント」は 3 段階。1: ポケットの位置（うすい球）、2: 鍵になるアミノ酸（結晶ポーズで水素結合・配位結合を作る上位 5 残基）、3: 本来のリガンドを緑で重ねる。
- 「おたすけ」で、答えの近くへ移動、自動で微調整（山登り）、答えの場所へ移動ができます。使った回は自己ベストに記録しません。
  ヒントとおたすけは、手動ドッキングと研究室ツールの両方で使えます（スクリーニングでは出しません）。
  正解のない分子（自分で追加した化合物）では、3 つ目のボタンが「ポケットに入れる」になり、短い自動ドッキングでポケットに入れます。
- 「コンピュータと対決」で、焼きなまし法による自動探索（強さ 3 段階）と点数を競えます。

## 研究室ツール

画面上部の「研究室ツール」で、自分の構造ファイルを読み込んで試せます。
ファイルはブラウザの中だけで処理され、どこにも送信されません（未発表の構造でも使えます）。

1. 構造ファイル（.pdb / .cif）を読み込む。NMR の複数モデルは 1 つ目だけ使う。
   手元にファイルがなければ、PDB ID を入れて RCSB（`files.rcsb.org/view/<ID>.cif`）から直接取得できる。
   届かないときは PDBe（`www.ebi.ac.uk/pdbe/entry-files/download/<id>.cif`）も試す。
2. 構造に入っている低分子を選ぶと、そこがポケットになる。点数は、その低分子の結晶構造でのポーズを 100 点として換算する。
   金属イオンを選ぶと、2.4 Å 以内にある小さなイオン（炭酸イオンなど）を 1 つの分子として一緒に扱う。
3. 自分の化合物（.sdf / .mol、V2000）を追加して、自動ドッキングで点数を比べる。
   英語名か CID を入れて PubChem（`pubchem.ncbi.nlm.nih.gov/rest/pug/compound/.../SDF?record_type=3d`）から取り寄せることもできる。
4. 「スコアの信頼性」で再ドッキング検証を実行できる。結晶構造のリガンドを置き直して、
   結晶と違う場所に高い点数が出ないかを調べる。出る場合、その系ではこのスコアで順位を比べても意味がない。

ネットからの取得は、ブラウザの `fetch` が相手サイトの CORS 許可に依存する。
同じホスト（files.rcsb.org、pubchem.ncbi.nlm.nih.gov）は、同梱している 3Dmol.js も
`$3Dmol.download` でブラウザから直接読み込んでいる。届かない場合は、その旨を表示して
手動のファイル読み込みに案内する。

原子の型付け（水素結合のドナー・アクセプター、疎水性、電荷、金属配位）は `structure.js` がブラウザ内で行い、
`tools/prepare_stage.py` と同じ結果になることを 1AVD・3IB0・1ERR で確認している。
SDF に水素が含まれていれば、それを使ってドナーを判定する。含まれていなければ結合距離と形から推定する。

## スクリーニング

画面上部の「スクリーニング」で、候補の分子の中から本物の相手を当てるモードになります。

- 候補は SMILES から RDKit で立体構造を作るので、結晶構造のない分子も入れられます。
- 各候補を自動ドッキング（焼きなまし法、40 試行 × 3000 ステップ）して、点数で順位を付けます。
- 候補の定義は `tools/screens/*.json`、データの生成は `python3 tools/make_candidates.py tools/screens/avidin.json`、検証は `node tools/validate_screen.js data/screen-avidin.js data/avidin-biotin.js` です。
- 検証結果（アビジン、8〜10 回ずつ）: ビオチン 85〜104 点、デスチオビオチン 82〜102 点、ヘキサン酸 37〜59 点、2-イミダゾリジノン 42〜59 点、カフェイン 25〜36 点。
  ビオチンとデスチオビオチンは、このスコアでは区別できません（実際にはビオチンのほうが強い）。結果画面でその旨を説明しています。

## ステージ

| ステージ | 構造 | 検証（偽の正解） |
|---|---|---|
| アビジン × ビオチン | 1AVD | 0 件 |
| ラクトフェリン × 鉄イオン + 炭酸イオン | 3IB0 | 0 件 |
| エストロゲン受容体 × ラロキシフェン | 1ERR | 0 件 |

検証で不採用にした題材: ラクトフェリン C ローブ × NSAIDs（3IB0、3IAZ、3IB1、3IB2）と β-ラクトグロブリン × レチノール（1GX8）。
浅い表面への弱い結合や、水素結合のない疎水性だけの結合は、このスコアでは結晶構造のポーズが最高点になりません。

## ステージの追加

リガンドが入った結晶構造（mmCIF）から作ります。リガンド名を `FE+CO3` のように `+` でつなぐと、複数の残基を 1 つの分子として扱います。
作ったデータは `index.html` の `<script src="data/…">` に 1 行足すと、ステージ一覧に出ます。

```
cd docking_lab
python3 tools/prepare_stage.py ../pdb_cache/1avd.cif BTN A avidin-biotin \
  --meta '{"title":"…","pdbId":"1AVD","proteinName":"…","ligandName":"…","blurb":"…"}'
node tools/validate_scoring.js data/avidin-biotin.js 60
```

検証では、ランダムな位置からの探索で「結晶構造から離れているのに高得点」のポーズが出ないことを確認します。
出る場合は、そのステージはスコアと正解が食い違うので、ゲームの題材に向きません。
